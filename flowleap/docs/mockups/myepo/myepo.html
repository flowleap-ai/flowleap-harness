What FlowLeap readsThe details of the 4 sources and where the secret stays
  • EP applications
    With your file references, from the portfolios that the account may read.
  • Mailbox letters
    With the application number, your reference and the document type. Mailbox letters to Intake come later; a downloaded letter then shows as read in MyEPO and stays unhandled there.
  • EPO due dates
    A check of your deadlines. Your deadline stays the source.
  • Pending fees
    For each application, with the amount and the due date.
The client secret stays on this installation and never goes to the agent or a log.
Set up the account at the EPO3 steps that your MyEPO administrator does once
  1. Ask the EPO for API access
    Your MyEPO company administrator writes to support@epo.org and asks for production client credentials for the MyEPO API. The EPO sends a client ID and a client secret to the administrator.
  2. Give the account only these rights
    In MyEPO, open Admin area › Group members and select the API account.
    Right in MyEPOSettingWhy
    Mailbox accessYesThe API reads the Mailbox only with this right.
    Fee payment rightsNo rightsFlowLeap does not pay fees.
    Admin rightsNoThe account must not change members or rights.
    Signing rightsNoFlowLeap does not sign.
    Sending rightsNoFlowLeap does not send to the EPO.
  3. Give it permission on your portfolios
    In Applications and patents, give the API account permission on each portfolio that FlowLeap may read. Without it, FlowLeap reads no application.
